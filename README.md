# SONIQX — Precision Audiology Platform

SONIQX is an app-based digital hearing screening platform designed to make preliminary hearing screening faster and more accessible using mobile/consumer devices.

The platform provides different experiences for children, adults, seniors, and schools.

> ⚠️ SONIQX is a preliminary hearing screening platform and does not replace diagnostic clinical audiometry.

## ⚠️ Disclaimer

SONIQX is intended for **preliminary hearing screening and awareness**.

It is **not a replacement for professional diagnostic audiometry or a clinical Pure Tone Audiometer**.

Users with abnormal or concerning screening results should be referred to a qualified hearing-care professional.
